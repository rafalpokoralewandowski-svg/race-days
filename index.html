Conflicts: a triangle marks a day when two or more series race; an amber mark means their event days overlap without a shared race day. The Conflicts panel lists every clash on the page. Untick a series' Show box to see the calendar without it.

Status row: click a day and choose REMOTE, ON-SITE or TRAVEL (or clear it for a day off). Each month counts the days; the summary adds up the page.

Truck lane: the day the IMSA transporter leaves the New Jersey workshop (solid) and its days on the road (tinted), arriving 2 days before each IMSA event; single driver, 11 h a day (FMCSA limit) at a 50 mph average.

Works offline: everything is inside this one file and your changes are saved on this device. Sync keeps the calendar the same on your computer and your iPhone through a private GitHub repository of yours; changes reach the other device within a minute while both are online, and changes made offline are merged when the device reconnects.

Dates are local to each circuit. IMSA and WEC dates are official; NLS 2027 dates are provisional; GTWC Europe 2027 Endurance race days are expected days until SRO publishes timetables. Sprint rounds race Saturday and Sunday. Formula E dates are race days; event days here start with the shakedown the day before, and double-headers race on both days. Connect Race Days

    Sync with GitHub

    Keeps this calendar the same on your computer and your iPhone. It is saved as one file, calendar.json, in a private GitHub repository of yours, and every save stays in the repository's history.

    On the iPhone, open the Camera, point it at this code and tap the link that appears. The page it opens copies the setup code for the Race Days app.

    The code contains your token. Hide it when you're done.

    From your computer: open Sync there, choose Show QR for iPhone and scan it with the Camera. The page that opens copies the setup code; then come back here, press and hold the box above, tap Paste and Connect.

    How to set up GitHub (once, about five minutes)
    1. Sign in at github.com (a free account is enough) and create a new repository, for example race-days-data. Set it to Private and tick Add a README.
    2. Make an access token: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Under Repository access choose Only select repositories and pick race-days-data. Under Permissions → Repository permissions set Contents to Read and write. Pick an expiry, generate it and copy the token.
    3. Here, enter your-name/race-days-data and paste the token, then Connect. The first device you connect uploads its calendar.
    4. Connect your iPhone: once this device is connected, choose Show QR for iPhone here and scan it with the iPhone camera. That device then loads the calendar from GitHub.
